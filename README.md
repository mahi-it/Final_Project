# Final Project - Global Happiness Report Analysis

### Introduction

The Global Happiness Report Analysis is a simple Python menu-driven program that allows users to load, explore, clean, analyze, and visualize data from a happiness report dataset.

The program provides different operations to work with DataFrames, perform mathematical calculations, generate descriptive statistics, and create visualizations. The program continues running until the user selects the **Exit** option.

### Features

- Load a happiness report dataset from a CSV file.
- Display the first five rows and last five rows of the dataset.
- Display column names, data types, and basic dataset information.
- Handle missing values by displaying, filling, dropping, or replacing them.
- Perform mathematical operations on numeric columns.
- Combine DataFrames using concatenation and merging.
- Split the dataset based on a selected column value.
- Search for values in the dataset.
- Sort and filter numeric and categorical data.
- Create pivot tables and calculate group averages.
- Re-index DataFrames and rename columns.
- Calculate sum, mean, median, standard deviation, variance, minimum, maximum, percentiles, and correlation.
- Perform group-wise statistical analysis.
- Generate different types of visualizations, including bar plots, line plots, scatter plots, pie charts, histograms, box plots, violin plots, and heatmaps.
- Save visualizations as image files.
- Provide a menu-driven interface for performing multiple operations in one execution.
