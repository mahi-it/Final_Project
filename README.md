# Expense Tracker

### Introduction

The Expense Tracker is a simple Python menu-driven program used to record, manage, and analyze daily expenses.

It allows users to add expenses, view summaries, filter expenses, generate reports, and visualize spending through different charts.

The program stores expense records in a CSV file and uses Pandas, NumPy, Matplotlib, and Seaborn for data analysis and visualization.

### Features

- Add and save new expenses.
- Calculate total, average, highest, and lowest expenses.
- Display category-wise spending.
- Filter expenses by category, date range, and amount range.
- Generate and save an expense report.
- Visualize expenses using a Bar Chart.
- Show spending distribution using a Pie Chart.
- Analyze monthly spending trends using a Line Plot.
- Display the distribution of expense amounts using a Histogram.
- Validate expense dates, amounts, categories, and descriptions.
- Handle missing values in the dataset.
- Store expense records in a CSV file.
- Menu-driven interface.
- Allows multiple operations in one execution.
